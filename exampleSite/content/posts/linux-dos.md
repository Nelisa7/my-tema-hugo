Para trabajar con sitios web estáticos, Hugo es una herramienta increíble por su velocidad. Aquí tienes los pasos básicos:

*1. Verificación e Instalación*
Para asegurarte de que está instalado, escribe en tu terminal:
hugo version

*2. Crear un nuevo sitio*
Para iniciar un proyecto desde cero, usa:
hugo new site nombre_de_tu_sitio

*3. Iniciar el servidor local*
Una vez dentro de la carpeta de tu proyecto, para previsualizar los cambios en tiempo real, ejecuta:
hugo server --config config.toml --ignoreCache

*4. Ver el resultado*
Abre tu navegador y entra en la dirección:
http://localhost:1313

¡Dominar estos comandos te permite levantar un sitio web profesional en cuestión de segundos!
